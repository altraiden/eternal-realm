# Eternal Realm

Изометрическая Dark Fantasy Action RPG для браузера: **эндгейм с первой минуты**. Герой создаётся сразу 70 уровня, появляется в хабе и идёт в порталы — без кампании.

Чистый JavaScript + Canvas 2D, сборка Vite, деплой на GitHub Pages через GitHub Actions.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | движение |
| ЛКМ, ПКМ, Q, E, R, F | шесть ячеек навыков (прицел — курсор) |
| Пробел | перекат с неуязвимостью |
| 1 | зелье |
| E (в городе) | говорить с жителем |
| I / K / P | сумка / навыки / таланты |
| T | портал домой |
| Esc | меню |
| Колесо мыши | масштаб |

Золото, материалы и руны подбираются сами. Предметы подбираются при проходе по ним (от редкости, заданной в фильтре) или кликом по подписи.

## Что реализовано (этап 1)

**Ядро**
- 10 классов, у каждого своя механика (ярость, комбо, жатва душ, чародейский щит…) и 3–4 специализации (34 всего).
- 60 активных навыков на 10 архетипах поведения (ближний бой, снаряды, новы, удары по земле, цепи, рывки, призыв, баффы, проклятия, ловушки). Любой класс может взять любой навык.
- 34 руны-модификатора навыков, меняющих поведение: расщепление, рикошет, раздвоение, возвращение, «падение с небес», «огненный змей», эхо, каскад, смена стихии и т. д.
- Формулы: броня против физического урона, сопротивления и пробивание, уклонение, блок, крит, вампиризм, снижение урона, конвертация урона, поджог / яд / кровотечение / шок / холод / заморозка / оглушение, проклятия.
- Древо талантов на 500 узлов (395 малых, 75 значимых, 20 ключевых, меняющих правила игры).

**Предметы**
- 12 слотов, 43 базовых типа, 9 редкостей (от обычной до божественной).
- 85 аффиксов с роллами и ростом от уровня предмета, 22 легендарных свойства с триггерами, 24 уникальных предмета (8 — эксклюзивная добыча боссов).
- Крафт у кузнеца: перековка, добавление и удаление аффиксов, повышение редкости, переброс значений, качество, заточка с шансом, пробуждение в древний предмет. Разбор, торговец, «тёмная лошадка», общее хранилище.

**Мир и эндгейм**
- Хаб «Последний оплот» с жителями: порталы, кузница, торговец, мастер рун, наставник, алхимик, хранилище, летопись.
- 6 активностей со своей добычей: Затерянные измерения, Бездонные подземелья (3 этажа, комнаты с ролями, ловушки), Бесконечная башня, Адские разломы, Царство боссов, Испытания хаоса.
- 74 монстра в 7 биомах, 6 типов ИИ, 12 способностей элиты.
- 12 боссов с тремя фазами и скриптами атак из 13 примитивов.
- 16 модификаторов порталов, 3 тайных сочетания, 6 уровней сложности, 60 уровней порталов.
- Уровни 70–100, парагон после 100 (с потолком), сохранение с контрольной суммой и резервной копией, экспорт / импорт.

## Чего пока нет

Из исходного ТЗ не сделано: мультиплеер и торговля между игроками, аукцион, древние храмы, охота на легендарных существ, вторжения, рейды, руны-предметы и артефакты как отдельная система развития, сетовые предметы, профессии, питомцы, бестиарий и кодекс, фракции, сезоны, звук. Количество контента меньше целевого (60 навыков из 200, 24 уникальных из 150, 12 боссов из 30). Баланс черновой.

## Разработка

```bash
npm install
npm run dev
```

```bash
npm run build
```

Весь контент описан данными в `src/data/` — новые навыки, монстры, боссы, предметы и модификаторы добавляются без правок движка.

| Путь | Содержимое |
| --- | --- |
| `src/data/` | классы, навыки, руны, предметы, монстры, боссы, активности, таланты |
| `src/stats.js`, `src/combat.js` | лист характеристик и конвейер урона |
| `src/skills.js` | движок навыков |
| `src/actors.js` | ИИ монстров, движок боссов, существа |
| `src/world.js` | генераторы карт |
| `src/items.js` | генерация предметов, дроп, крафт |
| `src/game.js`, `src/render.js` | игровой цикл, активности, рендер |
| `src/ui/` | интерфейс |

## Спрайты

Все спрайты — из набора [Pixel Art Atlas 1.4M](https://huggingface.co/datasets/Angais/pixel-art-atlas-1.4m) (Angais, CC0 1.0; изображения сгенерированы ИИ). В игре используется 419 спрайтов 16×16. Атлас пересобирается скриптом `tools/build_atlas.py` из распакованного архива набора; номера строк — в `tools/atlas_rows.json`.
